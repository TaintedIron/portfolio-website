# Portfolio Website

A responsive personal portfolio for David Giliberti, VP of Data Management & Quantitative Analysis. The site highlights professional experience, technical skills, education, and contact information.

## Features

- Responsive portfolio layout
- Light and dark theme toggle with saved preference
- Smooth section scrolling
- Scroll-based entrance animations
- Print-friendly resume support

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

No build tools or dependencies are required. Open `index.html` directly in a browser, or serve the folder with any local static web server.

For example, with Python:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Project Structure

- `index.html` - Portfolio content and page structure
- `styles.css` - Layout, responsive styles, and themes
- `script.js` - Theme switching, smooth scrolling, animations, and print behavior
